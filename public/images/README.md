# Pasta de Imagens

Coloque aqui os seus arquivos de imagem (mockups, mapas, bônus, etc.).

Exemplos de arquivos:
- `hero-mockup.png`
- `mapa-01.png`
- `mapa-02.png`
- `redacao-01.png`
- `oferta.png`

Depois de subir a imagem aqui, você pode usá-la no arquivo `/src/config.ts` apontando para `/images/nome-do-arquivo.png`.
